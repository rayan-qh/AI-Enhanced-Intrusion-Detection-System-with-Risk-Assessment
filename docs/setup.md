# دليل التشغيل

النسخة الحالية تدعم تشغيل لوحة Flask محليًا واستدلال صف CSV باستخدام أوزان موثوقة. تعليمات التثبيت الأساسية في README. يمكن تثبيت أدوات تحليل الدفتر باستخدام `python -m pip install -r requirements-research.txt`، ثم فتحه في بيئة Jupyter متاحة لديك. عدّل مسار Kaggle داخل نسخة الدفتر عند إعادة التجربة محليًا.

## Raspberry Pi وLinux

أنشئ البيئة بـ`python3 -m venv .venv` ثم ثبّت المتطلبات وشغّل `.venv/bin/python app.py`. توفر حزم الإصدارات المثبتة على ARM وأداء الجهاز لم يختبرا. شغّل Snort في بيئتك المصرح بها وفق إعداداته المحلية واجعل خرج alert_fast متاحًا داخل مجلد runtime. تعديل موقع السجل يتم عبر متغير البيئة IDS_RUNTIME.

## حالات الاستخدام

- دون بيانات، تعرض اللوحة «لا توجد بيانات حديثة».
- بعد `predict.py`، تعرض الفئة والاحتمالات ووقت الاستدلال.
- بعد 60 ثانية، توسم النتيجة المحفوظة بأنها قديمة.
- سجل Snort يعرض القاعدة والرسالة دون إسناد احتمال تصنيف لها.
- تتيح `/api/health` فحص حياة خدمة العرض فقط. تحميل النموذج يتم في أمر الاستدلال المستقل.

الخادم الافتراضي مربوط بعنوان loopback. للنشر العام يلزم خادم إنتاج وضبط وصول مناسب. المصادر التاريخية في archive للرجوع ولا تدخل مسار تشغيل التطبيق الجديد.
